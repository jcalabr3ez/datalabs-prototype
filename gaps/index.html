Questions we could not answer

Every question the ask engine declines is stored here, newest first. This list is the research agenda input: what visitors asked for and did not get is the strongest signal for what to verify and build next. This page is internal and not linked from the site.

Storage: Netlify Blobs, store unanswered-questions, written by the ask function whenever a question is declined. The listing endpoint is /.netlify/functions/questions; set a QUESTIONS_KEY environment variable in Netlify to require the access key above. Questions are visitor-typed text; treat them as unreviewed input.
